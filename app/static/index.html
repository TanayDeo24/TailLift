Long-tail query mapping for sparse search.

Maps rare queries to better-supported head queries using lexical, semantic, and historical support signals.

    04 — Method

    Tail query→ Lexical + semantic signals→ Train-only support prior→ Ranked head queries

    Candidates are ranked with a Jaccard lexical score, a sentence-transformer semantic similarity, and a popularity prior computed only from the training split — evaluation never leaks validation or test labels into that prior. The comparison ladder also evaluated a cross-encoder reranker; it was rejected after scoring lower on held-out data, and is shown here only as a labeled experimental option.

    This system was built without raw query timestamps or user identifiers, so session-level behavior such as reformulation or abandonment could not be measured and is not claimed. Splits are grouped by query so no tail query appears in more than one of train, validation, or test.
